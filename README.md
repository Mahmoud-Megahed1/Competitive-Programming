## Algorithmic Complexity Overview

| Category | Algorithm / Approach | Time Complexity | Space Complexity |
| :--- | :--- | :--- | :--- |
| **Graphs** | BFS with Path Reconstruction | O(V + E) | O(V) |
| **Backtracking** | N-Queens Solver | O(N!) | O(N) |
| **Number Theory** | Primes Generation (Sieve) | O(N log(log N)) | O(N) |
| **Strings & Arrays** | Two Pointers / Linear Scan | O(N) | O(1) auxiliary |
